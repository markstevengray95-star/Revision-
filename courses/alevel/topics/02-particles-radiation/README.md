# AQA Particle & Radiation Lab

Interactive A-level Physics teaching and revision app for **AQA Physics 7408**.

## Included

- Interactive 3D atomic structure and isotope model
- Strong nuclear force simulation
- Rutherford alpha scattering simulation
- Quark and hadron builder
- Antiparticle, annihilation and pair-production animation
- Beta-minus decay at quark level
- Photoelectric effect simulator
- Atomic energy-level / photon-transition simulator
- de Broglie wavelength visualisation
- Interactive topic/concept map linking the AQA content
- Particle atlas
- Conservation-law checker
- AQA-linked knowledge quiz
- AQA specification coverage map

## Specification coverage

The app covers AQA 7408 section **3.2 Particles and Radiation** and includes Rutherford scattering from **3.8.1.1 Nuclear Physics** as a closely linked extension.

## Running the app

The project is deliberately build-free. Open `index.html` in a modern browser, or host the repository with GitHub Pages / Netlify.

Three.js is loaded as an ES module from jsDelivr, so an internet connection is needed for the 3D renderer. The non-3D revision sections still provide useful content if WebGL/Three.js is unavailable.

## Visual-model note

Microscopic sizes and distances are deliberately exaggerated so that the models are visible. Quark positions, exchange particles, electron probability clouds and similar elements are teaching visualisations rather than literal photographs of subatomic objects.
