# A-Level Waves Learning Lab

Interactive teaching app for **AQA A-level Physics 7408, Section 3.3 Waves**.

Built from the layout and interaction patterns used in the Further Mechanics Learning Lab.

## Coverage
- Progressive waves, phase and wave speed
- Transverse and longitudinal waves
- Polarisation
- Superposition and stationary waves
- Interference and path difference
- Young double-slit experiment
- Diffraction and diffraction gratings
- Refraction, total internal reflection and optical fibres
- AQA Required Practical 1 and Required Practical 2
- Formula coaching, exam practice and specification tracking

## v18 learning + 3D upgrade
- All 12 guided lessons include an additional A-level depth layer with deeper explanations, equations, worked reasoning, misconceptions, exam-language guidance and lesson-specific investigations.
- All 9 core Simulation Lab models use lightweight rotatable 3D scenes with mouse/touch orbit controls and live physics parameters.
- Advanced Studio keeps its precision measurement canvases and adds linked 3D apparatus views for wave measurement, interference, Young's slits, single-slit diffraction, grating spectroscopy, optical fibres and string resonance.
- 3D animation is limited to active views to keep the app responsive on phones, tablets and school computers.
- Offline cache version: `waves-lab-v18`.

Open `index.html` in a browser or deploy the repository as a static site.
