# AQA equation and graph practice

The Equation Practice tab contains 272 equation forms and calculation tools. This includes equivalent forms, mathematical skills, core GCSE/A-level science and all five optional A-level Physics routes. It is a practice library, not a claim that every formula must be memorised or that every optional topic belongs in each student's course.

## Conventions and limits

- Units and assumptions are displayed for each equation. Angles in the interactive trigonometric examples are in radians. Temperature in gas/Arrhenius/Carnot calculations is in kelvin.
- Equivalent equations may have separate tools to practise choosing different givens. Constants are displayed; negative signs, vector directions and applicable branches are explained. Some multi-valued relationships deliberately offer only the supported unknowns, rather than pretending every inverse is unique.
- Statistics use clearly stated aggregate inputs or small category examples. Follow the formula and critical-value table provided in an assessment; the calculator does not infer statistical significance.
- Combined GCSE omits explicitly Separate Science tools. A-level Physics options are labelled in the topic filter. The teacher's “All core topics” selection excludes optional Physics topics.
- Worked examples display the selected formula, supplied values, required conversions, actual numerical substitution and answer. Final calculation and unit checks are automatic. Written reasoning is for review; its presence is not treated as proof of correct reasoning.
- Three-significant-figure tolerance is used for equation answers. Generated graph readings allow 0.5% with stated coordinate alternatives. Scores count only the first check; revealing a solution disables scored checking for that question.

## Graphs

58 generated scenarios span GCSE/A-level Physics, Chemistry and Biology. The original plotting tool also receives 53 additional datasets (all non-bar scenarios), alongside its four original experiments. Fresh values vary each task. Skills include values, relationships, signed/average gradients, tangent gradients, trapezium areas, half-life and bar comparisons/totals. Coordinate tables provide a keyboard/screen-reader alternative.

The graph library uses illustrative models, not experimental measurements or past-paper data. Scientific notes distinguish average gradients from tangents, distance from displacement, background-corrected decay, and correlation from causation.

## Homework

Preset buttons now apply their settings **and generate an immediate preview** for the current topic. A dedicated Auto-marked homework section provides recall, objective mixed and calculation sets. “Auto-marked only” never generates written questions; server marking and private keys use the existing assignment workflow. The Monitor section shows automatic points separately, using the latest attempt per student/assignment.

Teachers still choose a class and assign the preview explicitly. Changing a selection invalidates a preview. Unsupported/insufficient topics produce a visible error and clear the old preview; “All core topics” provides a broader bank without silently substituting a different topic.

No database schema or marking rules were changed in this revision. The previously applied 60-question capacity remains in use.
