# Expanded homework and Equation Practice

The existing Teacher assignment builder supports 3–60 questions and selectable mixes: suggested, mixed, multiple choice, missing words, written explanations or calculations. Preview and customise the work, then assign using the existing class, deadline, retry and solution-release controls. If a narrow selection cannot provide the requested number of distinct questions, the builder reports the available count rather than repeating questions or silently reducing the set.

Written questions draw on the reviewed 711-lesson course bank. Recall questions target scientific terms; multiple-choice alternatives use related concepts or the same topic. Combined Science filters exclude Separate Science lessons and explicitly Separate Science sentences. The 272-tool equation engine adds fresh calculation values and rearrangements, with Support, Standard and Stretch modes. Existing topic data challenges remain available where a topic has no matching equation. Missing-word and explanation answers use the existing teacher-review workflow; choice and final numerical answers use the existing server grading.

Equation Practice is a navigation tab and dashboard tool within the same deployment. Students can explore symbols, units, constants, conditions and rearrangements; follow a worked numerical example; then enter an equation, converted values, substitution working, final value and unit. Support finds the result, Standard can ask for any unknown, and Stretch introduces unit conversions. The expected answer is calculated from the displayed givens. Written working is recorded for self-review, not automatically awarded a correctness mark. Device progress counts the first check once and identifies complete first checks without viewing a solution.

Assigned questions and answer keys are frozen in the existing database workflow. Public student specifications contain no keys or embedded calculation objects. Private keys remain server-only. Cloud drafts, attempt history, teacher review, automatic marks, idempotency and delayed worked solutions retain their existing behaviour. Full answers remain in activity attempts rather than relying on the legacy notes field.

For an existing database, apply [supabase/homework-question-capacity.sql](../supabase/homework-question-capacity.sql). It changes only the question-count validation from 30 to 60 in the deployed private assignment function, preserving the current function body, ownership and permissions. It aborts if the validator has changed unexpectedly. Fresh databases use the updated limit in topic-activities.sql. Request payload and answer-size limits remain in place.

Validation includes all existing classroom and course tests, numeric consistency for every equation rearrangement, scientific notation, units, filtering, deterministic varied sets and removal of private keys from student specifications. Browser checks cover learning stages, feedback, fresh questions and responsive layout. Database verification uses a rolled-back transaction; real classroom data is not needed.

AQA expansion, graph scenarios and homework behaviour are documented in [aqa-equation-coverage.md](aqa-equation-coverage.md).
