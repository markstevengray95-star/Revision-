# Supplied revision question banks

Practice now has three sections: Lesson activities, Revision questions and Mark student answers. The new question-bank section is served by the same Revision app deployment.

The import contains all 106 supplied GCSE sets (Physics 35, Chemistry 36, Biology 35), comprising 143 answerable question parts. The import retains question wording, source typos, mark schemes, full-mark/example answers, partial answers, commentary, tables, symbols and equations. 83 referenced original diagram files retain their exact bytes. Word's positioned label boxes and connectors are rendered as SVG overlays; its structured equations become accessible MathML. Blank dotted answer lines become answer fields. Source Word files and their document metadata are not published.

Students must attempt every part in the selected set, using text or a sketch, before the mark scheme and supplied examples enter the visible review area. Changing an answer locks review again. Written answers are self-assessed; this feature does not pretend to automatically mark free text. Drafts, sketches, completion and self-assessed marks are saved on the current device. This is a self-study reveal gate, not a secure examination boundary: the static source data can be inspected or fetched directly.

Mark student answers uses excerpts of the supplied partial answers and full-mark answers. Answer order is shuffled, numeric selections are required for every example, and a first check reveals the supplied score and original commentary. Examiner annotations and score labels are removed from the exercise excerpts, while the complete unedited commentary remains in review. There are 103 eligible sets with at least two scoreable examples. Two Physics sets provide a single annotated full-mark example rather than separate full/partial answers. Chemistry set 12 has an overall awarded score whose total does not match the supplied excerpt's answer parts; it is retained in Revision questions with its original answers and commentary, but omitted from the marking exercise rather than inventing a score.

The importer also handles Chemistry set 11's unlabelled first part without adding a label to its source prompt. Answer-field labels use its mark scheme reference. Physics set 33 retains the source answer's question-number typo while associating the answer with its containing set. No scientific wording, numerical values or awarded marks have been corrected.

`tools/question-bank/source-manifest.json` records source file hashes, counts and diagram hashes. To reproduce the import, run `scripts/import-question-docs.py --sources <directory>` with the three supplied filenames. It uses Python's standard library and verifies every non-whitespace source character across all 424 question, scheme, model and commentary sections. Positioned labels and isotope prescripts retain their visual ordering. Builds use committed assets and do not require Word, the original files or a document converter. `tests/source-question-bank.cjs` checks import coverage, original diagram hashes, score-to-part correspondence, invalid grades, completion gating and draft validation.

This change does not write classroom assignments, teacher grades or student records to the cloud database.
